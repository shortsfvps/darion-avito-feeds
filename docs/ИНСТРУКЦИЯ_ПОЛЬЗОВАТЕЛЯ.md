# Руководство пользователя: Система автозагрузки фидов Авито компании «Дарион Свет»

Данный документ предназначен для менеджеров и специалистов компании **«Дарион Свет»**, ответственных за ведение каталога товаров и публикацию объявлений на классифайде **Авито (Avito)**.

---

## Раздел 1. Назначение системы и состав 8 XML-фидов

Система автоматизирует выгрузку ассортимента светотехники компании в личный кабинет Авито через официальный протокол **«Автозагрузка» (Avito XML Feed Format v.3)**.

### Как работает система:
1. **Синхронизация остатков и цен**: Программа автоматически подключается к корпоративной Google Таблице с актуальными остатками склада в Санкт-Петербурге (`Остатки СПБ запасы`) и забирает свежие цены и количество свободного товара.
2. **Фильтрация наличия**: В выгрузку попадают **только товары в наличии** (остаток $> 0$). Позиции с нулевым или отрицательным остатком автоматически исключаются, что предотвращает штрафы Авито за продажу отсутствующих позиций.
3. **Формирование продающих карточек**:
   - Автоматическая распаковка архивов дополнительных фотографий в галерею прямых ссылок Авито.
   - Генерация структурированного продающего описания с техническими характеристиками (мощность, световой поток, цоколь, IP-защита, срок службы, габариты и гарантия).
   - Блок преимуществ «Дарион Свет» (гарантия производителя, отгрузка из СПб, безналичный расчет с НДС 22%, доставка по всей России).
4. **Разделение на 8 специализированных фидов**:
   Товары распределяются по 8 XML-файлам в папку `output/` согласно категориям Авито:

| № | Имя фида в папке `output/` | Категория на Авито | Назначение и типы продукции |
|---|---|---|---|
| **1** | `led_luminaires_feed.xml` | Для дома и дачи → Освещение | Светодиодные промышленные, уличные, консольные и универсальные светильники (Virona и др.) |
| **2** | `track_systems_feed.xml` | Для дома и дачи → Освещение → Трековые системы | Трековые светильники, шинопроводы, коннекторы и комплектующие |
| **3** | `chandeliers_feed.xml` | Для дома и дачи → Освещение → Потолочные светильники | Люстры, подвесные и накладные потолочные светильники |
| **4** | `lamps_feed.xml` | Для дома и дачи → Освещение → Лампочки | Светодиодные, филаментные и энергосберегающие лампы |
| **5** | `lighting_fixtures_feed.xml` | Для дома и дачи → Освещение → Светильники | Бра, споты, настенные и декоративные подсветки |
| **6** | `lamp_luminaires_feed.xml` | Для дома и дачи → Освещение | Светильники под сменные лампы |
| **7** | `electrics_feed.xml` | Ремонт и строительство → Электрика | Блоки питания, LED-драйверы, кабели, патроны, клеммы |
| **8** | `other_goods_feed.xml` | Для дома и дачи / Оборудование | Прочие товары, кронштейны, торговый инвентарь |

> **Важная особенность**: Даже если в какой-либо категории в данный момент нет остатка, скрипт формирует валидный каркас фида. Это гарантирует, что постоянные ссылки в личном кабинете Авито всегда остаются активными и робот Авито не выдает ошибку 404.

## Раздел 2. Как запустить обновление вручную (в 1 клик)

Если менеджер обновил файл номенклатуры `data/Продукты (19).xlsx` или изменились остатки в Google Таблице и требуется немедленно обновить фиды:

1. Откройте рабочую папку проекта:
   `D:\Automatizations\Fl.ru\Darion свет\`
2. Дважды кликните по файлу **`run.bat`**.
3. Откроется окно консоли, в котором скрипт последовательно выполнит:
   - Проверку наличия Python.
   - Скачивание свежих остатков и цен из Google Таблицы.
   - Обработку номенклатуры и генерацию всех 8 фидов.
   - Публикацию на сервер (если в `config.py` включен FTP/SFTP) либо сохранение в папку `output/`.
4. В конце появится сообщение:
   `[УСПЕХ] Все 8 XML-фидов успешно сформированы и готовы к загрузке в Авито!`
5. Нажмите любую клавишу для закрытия окна.

## Раздел 3. Как настроить автоматическое ежедневное обновление через «Планировщик заданий Windows»

Чтобы фиды обновлялись автоматически (например, каждое утро в 08:00 перед началом рабочего дня), настройте стандартный Планировщик Windows за 3 простых шага:

### Шаг 1. Открытие Планировщика заданий
- Нажмите комбинацию клавиш `Win + R` на клавиатуре.
- В появившемся окне введите `taskschd.msc` и нажмите **Enter** (или найдите в меню «Пуск» приложение *«Планировщик заданий»* / *Task Scheduler*).

### Шаг 2. Создание новой задачи
- В правой колонке нажмите **«Создать простую задачу...»** (Create Basic Task).
- **Имя**: `Дарион Свет - Обновление фидов Авито`.
- **Описание**: `Ежедневная генерация 8 XML-фидов для автозагрузки Авито`.
- Нажмите **Далее**.
- **Триггер (Когда запускать задачу)**: выберите **«Ежедневно»** (Daily) → нажмите **Далее**.
- **Время**: укажите желаемое время запуска (рекомендуется **08:00**, повторять каждые **1 день**) → нажмите **Далее**.

### Шаг 3. Указание исполняемого файла и рабочей папки
- **Действие**: выберите **«Запустить программу»** (Start a program) → нажмите **Далее**.
- В поле **Программа или сценарий** (Program/script) укажите путь к пакетному файлу:
  `D:\Automatizations\Fl.ru\Darion свет\run.bat`
- В поле **Рабочая папка** (Start in) **ОБЯЗАТЕЛЬНО** укажите путь к директории проекта (без кавычек):
  `D:\Automatizations\Fl.ru\Darion свет`
- Нажмите **Далее** и затем **Готово** (Finish).

*Готово! Теперь система будет самостоятельно обновлять все фиды каждое утро по расписанию.*

## Раздел 4. Как подключить фиды в личном кабинете Авито

Для каждого из 8 направлений в Авито настраивается отдельная ссылка автозагрузки.

### Пошаговый алгоритм:

1. **Авторизация**:
   Войдите в личный кабинет компании на [Avito.ru](https://www.avito.ru/) под профилем «Дарион Свет» с подключенным тарифом с Автозагрузкой.
2. **Переход в раздел «Автозагрузка»**:
   В правом верхнем меню перейдите в: **Для бизнеса** → **Автозагрузка** (или по прямой ссылке `https://www.avito.ru/autoload`).
3. **Добавление расписания и ссылки на фид**:
   - Нажмите кнопку **«Настроить автозагрузку»** (или **«Добавить файл»**).
   - В поле **«Ссылка на файл»** вставьте URL соответствующего фида:
     * Для локального веб-сервера / хостинга компании:
       `http://darion-svet.com/avito_feeds/led_luminaires_feed.xml`
       `http://darion-svet.com/avito_feeds/track_systems_feed.xml`
       `http://darion-svet.com/avito_feeds/chandeliers_feed.xml`
       `http://darion-svet.com/avito_feeds/lamps_feed.xml`
       `http://darion-svet.com/avito_feeds/lighting_fixtures_feed.xml`
       `http://darion-svet.com/avito_feeds/lamp_luminaires_feed.xml`
       `http://darion-svet.com/avito_feeds/electrics_feed.xml`
       `http://darion-svet.com/avito_feeds/other_goods_feed.xml`
     * Либо загрузите файл вручную из локальной папки `D:\Automatizations\Fl.ru\Darion свет\output\`.
4. **Настройка времени проверки**:
   - Рекомендуется выставить время автоматической загрузки на **09:00** (через 1 час после срабатывания планировщика в 08:00, чтобы файлы гарантированно успели сформироваться и загрузиться на сервер).
5. **Сохранение и проверка**:
   - Нажмите кнопку **«Проверить файл»**. Робот Авито проверит структуру фида и выведет статус: *"Ошибок не обнаружено"*.
   - Активируйте переключатель автозагрузки.

## Раздел 5. Настройка публикации (FTP / SFTP) в `config.py`

По умолчанию фиды сохраняются в локальную папку `output/` (`UPLOAD_METHOD = 'local'`).

Если вы хотите, чтобы скрипт после генерации сразу выгружал фиды на сайт `darion-svet.com`:
1. Откройте файл `config.py` в любом текстовом редакторе (Блокнот, VS Code).
2. Замените:
   ```python
   UPLOAD_METHOD = 'ftp'  # или 'sftp'
   ```
3. Заполните реквизиты доступа:
   ```python
   FTP_HOST = 'ftp.darion-svet.com'
   FTP_USER = 'ваш_логин'
   FTP_PASS = 'ваш_пароль'
   FTP_REMOTE_DIR = '/public_html/avito_feeds'
   FTP_PUBLIC_URL_BASE = 'http://darion-svet.com/avito_feeds'
   ```
4. Сохраните файл. При следующем запуске `run.bat` файлы автоматически загрузятся на ваш веб-сервер.
