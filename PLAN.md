# План: Корректировка полей Title и Description для фидов Авито

## 1. Что делаем
Корректируем логику генерации тегов `<Title>` и `<Description>` в скрипте `scripts/generate_feeds.py` под строгие требования Авито и уточнения клиента:
- **Title**: формат `«[Название] ([Артикул])»`, гарантированная длина строго `<= 50` символов с корректной обрезкой базового имени по границам слов без обрыва на полуслове и без висячих знаков пунктуации.
- **Description**: СНАЧАЛА идет структурированный блок технических характеристик товара, затем НИЖЕ — полное продающее описание из столбца AH (34) без обрезки текста, далее условия компании «Дарион Свет» и контакты, с жестким контролем длины всего описания `<= 5 000` символов.

## 2. Из каких частей состоит решение
1. **Модернизация `format_title(name, sku, max_len=50)`**:
   - Формирование суффикса ` ({sku})`.
   - Вычисление доступной длины под базовое наименование `avail_len = max_len - len(suffix)`.
   - Очистка базового имени от старых дублирующих артикулов/скобок на конце.
   - Обрезка базового названия по границе слов в пределах `avail_len`, удаление концевых знаков ` ,.-;/`.
   - Сборка итогового заголовка с проверкой `len(title) <= 50`.
2. **Модернизация `DescriptionBuilder.build_description(prod)`**:
   - Формирование блока технических характеристик `[ТЕХНИЧЕСКИЕ ХАРАКТЕРИСТИКИ]` в начале описания.
   - Получение полного текста из `extra_desc` (столбец AH, ячейка 34).
   - Если текст в AH есть: размещение его НИЖЕ под характеристиками отдельным блоком `[ОПИСАНИЕ И ПРЕИМУЩЕСТВА]`.
   - Блок условий компании «Дарион Свет» и призыв к действию.
   - Контроль лимита Авито: если суммарный объем превышает 5000 символов, безопасная обрезка до 5000 знаков с сохранением валидности CDATA.
3. **Локальная сборка и верификация**:
   - Запуск `python scripts/generate_feeds.py`.
   - Проверка позиций: `V1007` (уличное освещение, есть описание AH) и `14690612038169` (потолочное освещение).
   - Автоматическая валидация: проверка, что ни один заголовок во всех 8 фидах не превышает 50 символов.
4. **Фиксация и деплой**:
   - Создание отчета `REVIEW.md`.
   - `git add .`, `git commit -m "fix: update title length formatting with sku and full description from column AH"`.
   - `git push origin main` и контроль срабатывания GitHub Actions.

## 3. Какие файлы будут созданы или изменены
- `scripts/generate_feeds.py` — обновление методов `format_title`, `build_description`, вызова `format_title(prod["name"], prod["sku"])`.
- `output/*.xml` — автоматическое обновление сгенерированных XML-фидов.
- `PLAN.md`, `REVIEW.md` — отчетные файлы процесса разработки.

## 4. Возможные риски
- Длинный артикул оставляет мало места под название товара: решается корректной обрезкой по словам.
- Описание вместе со спецификациями и маркетинговым текстом может превысить 5 000 символов: решается встроенным валидатором длины с лимитом 5 000 знаков.
